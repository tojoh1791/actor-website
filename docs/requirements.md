# Requirements

## Project purpose

The website will serve as the official website for the actor and their business activities

The main purposes of the website are to:
- Present the actor and their background
- Promote upcoming talks and other events
- Provide information about the book based on the actor's life
- Make it easy for visitors to discover upcoming events
- Provide a professional way for potential clients and organizers to get in contact
- Support future expansion of the actor's business activities

## Public website

- Display information about the actor
- Display upcoming events
- View details for an event
- Contact information
- Responsive design

### Not yet decided

- Link to external ticket sales

### Pages 

#### Home
- Introduction to the actor
- Hero image
- Short presentation
- Preview of upcoming events

#### About
- Biography
- Information about acting work and other relevant work

#### Events
- Display upcoming events in chronological order
- Each event is displayed as an expandable interactive card
- The collapsed card displays:
    - Date
    - Event title
    - Location
- Selecting an event expands the card to display additional information
- Additional information may include:
    - Description
    - Time
    - Address
    - Organizer
    - External information or ticket link
- Past events should not appear as upcoming events
- The event card must work on both desktop and mobile
- The event card must be keyboard accessible

#### Contact 
- Display relevant contact informasjon
- Contact/booking request form: Planned for a future version


## Administration

- Administrator login
- View events
- Create events
- Edit events
- Delete events
- Publish/unpublish events

## Open questions

- Will events require tickets or registration?
- Should past events be publicly visible?
- Should event images be uploaded through the administration system?
- Will anyone other than the actor need administrator access?

## Non-functional requirements

- The website must be responsive and work well on desktop and mobile devices
- The website should be accessible and follow relevant WCAG principles
- The website should have good loading performance
- The public pages should be optimized for search engines
- Administration functionality must require authentication
- Sensitive information such as passwords and credentials must not be stored in source code

## Future features

- Contact/booking request form
- Dedicated page for the book
- Manageent of website content through the administration panel
- Event categories
- Display of past events
- Additional administrator/editor accounts
