# Database

Database: PostgreSQL

## Initial entities

### Events

Represents any public event involving the actor, including talks, appearances and other future event types.
Planned information:

- ID
- Title
- Description
- Start date/time
- End data/time
- Location
- Address
- Image
- Publication status
- Created timestamp
- Updated timestamp

Ticketing and registration requirements have not yet been decided.

### User

Used for administration authentication.

Exact database schema will be designed before backend implementation.
